# 📄 التقرير الشامل والشرح التفصيلي لنظام المقابلات الذكي (Smart HR Tech System)

---

## 📌 1. نظرة عامة على المشروع (Project Overview)

**نظام المقابلات الذكي (Smart HR Tech System)** هو منصة هجينة متكاملة تعتمد على الذكاء الاصطناعي لإجراء وتوثيق وتحليل المقابلات الوظيفية تلقائياً وبشكل حي (Real-time).

### 🎯 الأهداف الأساسية:
1. **أتمتة المقابلات (Interview Automation):** تمكين المرشحين من إجراء المقابلات عبر الإنترنت مع مساعد ذكي يسأل ويسجل الإجابات.
2. **التحليل الحركي والصوتي واللفظي (Multi-modal AI Analysis):**
   - **تحليل الوجه وحركة العين (Face & Gaze Tracking):** لكشف التركيز ولغة الجسد والانتباه.
   - **التعرف على الأجسام (YOLO Object Detection):** لكشف النزاهة والمراقبة (مثل وجود أشخاص آخرين أو استخدام الهاتف).
   - **تحويل الصوت إلى نص (Speech-to-Text):** باستخدام نموذج Faster-Whisper لتحويل إجابات المرشح لنصوص مكتوبة.
   - **تحليل نبرة الصوت (Audio Prosody):** لكشف مستوى الثقة والتردد والهدوء.
3. **لوحة تحكم للموارد البشرية (HR Dashboard):** لإدارة الوظائف، ودعوة المرشحين، ومراجع النتائج والتقارير التفصيلية المشفوعة بتقييمات الذكاء الاصطناعي.

## 🏗️ 2. المعمارية الهندسية للنظام (System Architecture)

يعتمد النظام على **معمارية الخدمات الدقيقة المدمجة (Hybrid Microservices Architecture)**، وتتكون من 4 أجزاء رئيسية:

```
                  ┌───────────────────────────────────────────┐
                  │          المتصفح (Browser / UI)            │
                  │   Vue 3 + Inertia.js + Tailwind CSS       │
                  └─────────────┬───────────────┬─────────────┘
                                │               │
                  HTTP / REST   │               │ WebRTC / Streaming
                                ▼               ▼
┌───────────────────────────────────┐       ┌───────────────────────────────────┐
│     Laravel 11 (Web Backend)      │       │     FastAPI (AI Engine)           │
│  - إدارة المستخدمين والوظائف       │       │  - معالجة البث الحي (WebRTC)      │
│  - التوكينات وجلسات المقابلات     │       │  - نماذج MediaPipe + YOLO         │
│  - تقديم واجهات Vue عالي السرعة   │       │  - تحويل الصوت لنص (Whisper)      │
└─────────────────┬─────────────────┘       └─────────────────┬─────────────────┘
                  │                                           │
                  │              PostgreSQL 16                │
                  └───────────────────► ◄─────────────────────┘
                               (قاعدة البيانات الموحدة)
                                          │
                                       Redis 7
                              (الطوابير + Realtime Cache)
```

## 🗄️ 4. هيكلية البيانات وقواعد البيانات (Database Schema & Models)

يستخدم المشروع قاعدة بيانات موحدة **PostgreSQL 16** تضمن التزامن التام بين Laravel و FastAPI:

### الجداول والنماذج الأساسية:
1. **`users`**: حسابات مسؤولي وموظفي الـ HR (البريد، كلمة المرور المفرمة).
2. **`candidates`**: بيانات المرشحين للمقابلات (الاسم، البريد الإلكتروني، السيرة الذاتية).
3. **`interviews`**: بيانات الوظيفة والأسئلة المحددة للمقابلة ومعايير التقييم.
4. **`interview_sessions`**:
   - تحتوي على الجلسة الحية للمرشح (`token` فريد).
   - تخزن حالة المقابلة (`pending`, `in_progress`, `completed`).
   - تخزن النتائج والتقارير المكتملة المخرجة من FastAPI (الدرجات، تفريغ الصوت، ملاحظات النزاهة).
5. **`time_windows`**: المواعيد الزمنية المتاحة للمقابلات.

## ⚙️ 5. دورة تدفق البيانات (Data Flow Sequence)

1. **إعداد المقابلة:**
   - يقوم مسئول الـ HR عبر لوحة التحكم (`Dashboard.vue`) بنشر وظيفة وتوليد رابط مقابلة للمرشح يحتوي على `token`.
2. **انضمام المرشح:**
   - يفتح المرشح الرابط وتظهر له غرفة المقابلة (`InterviewRoom.vue`).
   - يتصل المتصفح بـ **FastAPI** عبر **WebRTC** على المنفذ `8001` لفتح بث دقيق للصوت والصورة.
3. **التحليل الحي (Live AI Pipeline):**
   - **البث المرئي:** يحلل `face.py` اتجاه نظر المرشح و `yolo_pipe.py` لكشف البيئة المحيطة.
   - **البث الصوتي:** يتم تجميع المقطع الصوتي وتحويله عبر `whisper_pipe.py` إلى نص فور الانتهاء من الإجابة.
   - يتم حساب درجات الثقة ونبرة الصوت عبر `prosody.py`.
4. **حفظ وتحديث النتائج:**
   - يقوم `quality_gate.py` بتجميع كافة المؤشرات وإخراج التقييم النهائي وتخزينه في جدول `interview_sessions` في قاعدة البيانات.
   - يظهر التقرير فوراً لمسئول الـ HR على لوحة التحليل في Laravel.

## 🚀 6. دليل التشغيل والصيانة (Operational Guide)

### 1. تشغيل الخدمات الخلفية وقواعد البيانات (Docker Services):
في المجلد الرئيسي `HR Tech`:
```powershell
docker-compose --env-file .env.docker up -d
```
*سيعمل كل من PostgreSQL على المنفذ 5432، Redis على 6379، و FastAPI على 8001.*

### 2. تشغيل مشروع Laravel والواجهات:
في مجلد `laravel`:
```powershell
# تهيئة وتحديث الجداول عند الحاجة
php artisan config:clear
php artisan migrate

# تشغيل خادم Laravel
php artisan serve

# تشغيل خادم تطوير واجهات Vue 3 (في نافذة Terminal أخرى)
npm run dev
```

### 3. روابط الفحص والوصول:
- **الموقع الواجهة الرئيسية (Laravel + Vue):** `http://localhost:8000`
- **فحص صحة محرك الذكاء الاصطناعي (FastAPI Health):** `http://localhost:8001/health`
- **توثيق وتجربة واجهات FastAPI (Swagger UI):** `http://localhost:8001/docs`
